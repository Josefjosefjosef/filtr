Kodex anonymity

  • ✓ Nesledujeme jednotlivé osoby.
  • ✓ Nevytváříme reklamní profily.
  • ✓ Neprodáváme data.
  • ✓ Nepředáváme analytická data třetím stranám.
  • ✓ Nepoužíváme externí analytické skripty.
  • ✓ Neukládáme obsah osobních modulů.
  • ✓ Měříme pouze anonymní agregované statistiky.
  • ✓ Ochrana proti podvodům neslouží ke sledování uživatelů.
  • ✓ Reklamní statistiky jsou měřeny anonymně a agregovaně.
  • ✓ Reklamní pozice mohou vznikat dynamicky podle objednávky, ale nikdy bez profilování lidí.
