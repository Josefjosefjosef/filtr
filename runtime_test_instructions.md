# Runtime Test - Instrukce

1. Otevři: `https://infouzel.cz/projects/?debug=1`
2. Hard reload: `Ctrl+F5` (nebo `Cmd+Shift+R`)
3. Otevři DevTools Console (F12)
4. Zkopíruj celý obsah z `runtime_test_console_commands.js`
5. Vlož do konzole a stiskni Enter
6. Počkej 4 sekundy
7. Zkopíruj celý výstup od `=== RUNTIME TEST REPORT ===` až do konce
8. Pošli výstup do REPORTu
