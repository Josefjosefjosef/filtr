# Runtime Test - Instrukce

1. Otevři: `https://infouzel.cz/projects/?debug=1`
2. Hard reload: `Ctrl+F5` (nebo `Cmd+Shift+R` na Mac)
3. Otevři DevTools Console (F12)
4. Zkopíruj celý obsah z `runtime_test_console_commands.js`
5. Vlož do konzole a stiskni Enter
6. Počkej 4 sekundy
7. Zkopíruj vše od `=== RUNTIME TEST REPORT ===` až po `=== END REPORT ===`
8. Pošli mi výstup + napiš, jak rychlé byly kliky na 5 titulků (rychlé/pomalé + odhad v sekundách)
